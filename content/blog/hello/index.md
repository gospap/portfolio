The previous version of this site was a Next.js 16 app: React Three Fiber, a
bent-card carousel, a project helix the camera flew down, custom shaders, and a
motion library written around half-lives rather than blend factors so it behaved
the same at 30 and at 144 fps. I liked building it. It also meant that reading
two paragraphs about a project required booting a 3D scene first.

So it now runs on [Zola](https://www.getzola.org) with the
[Duckquill](https://codeberg.org/daudix/duckquill) theme. Static HTML, no
mandatory JavaScript, and a build that finishes in under half a second. The
things worth keeping came across: the writing, both languages, and the
structured data that tells a search engine this site is about a person.

More to follow here.
